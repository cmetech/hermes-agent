# v3.0.3 follow-up: recurring workflow schedules

Status: deferred and non-normative for Workflow v3.0.3 Revision 7.

Revision 7 adds one-shot `schedule_at` admission only. Recurrence, missed-run
policy, timezone rules, edit semantics, ownership, and series cancellation are
not part of the v3.0.3 scheduler contract.

A future proposal should decide whether recurrence remains a Cron-owned wrapper
or becomes a workflow-native series without creating a second scheduler.
One-shot identity, fire-time authorization, bounded wake behavior, retained
cancellation evidence, and the existing Cron behavior must remain intact.
