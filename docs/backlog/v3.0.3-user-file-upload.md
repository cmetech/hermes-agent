# v3.0.3 follow-up: user file upload

Status: deferred and non-normative for Workflow v3.0.3 Revision 7.

Revision 7 accepts declared text inputs and digest-authenticated bundled
fixtures. It does not accept caller-selected local paths or upload arbitrary
user bytes through Desktop.

A future design must define authenticated upload ownership, read-once staging,
size and aggregate limits, filename/path containment, content handling,
retention, redaction, idempotency, and cleanup before adding a public file
input. It must preserve the current verified-fixture channel and must not
reopen source paths after verification.
