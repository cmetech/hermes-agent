# v3.0.3 follow-up: CLI scheduling convergence

Status: deferred and non-normative for Workflow v3.0.3 Revision 7.

Desktop Run later uses workflow-native, one-shot `schedule_at`. The legacy CLI
scheduling showcase intentionally retains its schedule-kind confirmation and
Cron creation behavior.

A future convergence design must choose one user-visible ownership model,
provide migration and cleanup semantics for existing Cron records, and retain
honest confirmation copy. It must not silently create both a Cron job and a
workflow-native scheduled run or weaken the current one-shot fire-time
authorization contract.
