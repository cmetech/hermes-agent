# Engineering Assessments

Durable source-based assessments used to plan migrations and capability work.

- [LOOP24 workflow and tool migration](loop24-migration/README.md) — compares
  the legacy Langflow portfolio and supporting tools with the Co-worker Archon
  workflow/runtime and edge-capability architecture.
- [Glean MCP authentication](2026-09-04-glean-mcp-authentication.md) — records
  the `super-cli`/Kiro reverse-engineering findings, compares Hermes' static
  bearer and OAuth paths, and provides a safe continuation runbook.

Assessments describe verified current state and recommended direction. They do
not authorize implementation, branch integration, or release work.
